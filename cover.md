# Leanpub Cover Prompt

Use this prompt with ChatGPT's image generation tool to create the Leanpub cover image.

---

## Prompt for ChatGPT

You are an award-winning book cover designer and illustrator. Create a print-ready Leanpub book cover as a single PNG image, exactly **2100 pixels wide × 3000 pixels high** (7:10 portrait), RGB, no transparency, no crop marks, no watermark.

### Book details

**Title:** Build a Mini Coding Agent in JavaScript  
**Subtitle:** A tiny Node coding-agent harness, built one runnable stage at a time  
**Author:** Craig West  
**Optional badge:** No framework · No agent SDK · One dependency

### Design direction

Create a modern technical-editorial cover for developers. The feel should be a well-made programming book from a small independent press: confident, warm, minimal and precise. It must not look like a generic AI stock cover, a cyberpunk poster, or a robot illustration.

The cover should communicate:

- a coding agent built from small, understandable parts;
- a conversation that grows into tools, memory and a loop;
- clean engineering rather than hype;
- a book you can read, run and trust.

### Visual concept

Use a single luminous **agent loop** as the central image: a clean technical diagram on a deep charcoal field.

The loop starts at the lower left as a simple chat bubble. It curves upward through a small set of elegant tool glyphs — file, pencil, terminal, memory, hook — and returns to the bubble with an arrow, forming one continuous path. The path should read as one idea, not a pile of icons. Use thin ivory and terracotta linework, a subtle warm glow, and a faint blueprint grid.

The visual should suggest: **conversation → hands → memory → loop**. Keep the glyphs abstract and minimal. Do not label them with extra words.

### Composition

- **Background:** deep charcoal / graphite, not pure black, with a very subtle paper or noise texture.
- **Top third:** the title, large and dominant.
- **Under the title:** the subtitle in a smaller, quieter face.
- **Middle:** the central agent-loop diagram, with generous breathing room.
- **Bottom:** “Craig West” in clean, confident type.
- **Optional badge:** place “No framework · No agent SDK · One dependency” as a small monospaced strip near the bottom, above the author name. Omit it if it makes the cover busy.
- **Safe margins:** keep all text and critical artwork at least 180 px from every edge.

### Typography

Use a high-contrast modern serif or a confident geometric sans for the title. The title must remain readable at thumbnail size. Use a monospaced or grotesque sans for the subtitle, badge and author line.

Suggested line breaks for the title:

> Build a  
> Mini Coding Agent  
> in JavaScript

Do not add any other words. Do not misspell the title, subtitle or author name.

### Colour palette

Use a restrained three-colour system:

- **Charcoal:** `#1b1f24`
- **Warm ivory:** `#f4efe4`
- **Terracotta accent:** `#d97757`

Optional secondary accent: muted amber `#e0b15a` or dusty teal `#6f9f9a`, used sparingly in the diagram only.

### Style

- Flat vector-inspired illustration with subtle depth.
- Crisp edges, generous negative space, print-quality finish.
- Warm, editorial, technical, calm.
- No photographic elements.
- No human faces.
- No robot mascots.
- No neon gradients.
- No glossy 3D renders.
- No dense microtext.
- No fake publisher logos.
- No extra labels, badges or slogans beyond the text specified above.

### Text that must appear

Exactly these words, with correct spelling:

1. **Build a Mini Coding Agent in JavaScript**
2. **A tiny Node coding-agent harness, built one runnable stage at a time**
3. **Craig West**
4. Optional: **No framework · No agent SDK · One dependency**

### Output requirements

Generate a single PNG at exactly **2100 × 3000 px** with ChatGPT's image generation tool.

ChatGPT image generation can sometimes distort small text. Render the title, subtitle and author name as cleanly and accurately as possible. If any word is misspelled, clipped or unreadable, do not deliver that version: regenerate it. If the image tool cannot reproduce the text reliably, create a self-contained SVG or HTML/CSS cover at exactly 2100 × 3000 px using vector shapes and real SVG text, then export it to PNG. The final deliverable must be a PNG at the required dimensions.

Before finishing, check:

- the title is readable at 200 px wide;
- no text is clipped or too close to the edge;
- the author name is spelled “Craig West”;
- the subtitle is spelled correctly;
- only the approved words appear;
- the file is exactly 2100 × 3000 px.

---

## Art-direction notes for review

The cover should feel like the book: small, precise, warm and honest. The strongest idea is the single path from conversation to tools and back again. If the diagram becomes busy, remove glyphs rather than adding detail.

The thumbnail test matters more than the full-size detail: a reader should recognise “coding agent” and read the title before they see the fine linework.
